# EventLite – Frontend (Next.js)

EventLite is a modern, real-time event booking platform.  
This repository contains the **frontend application** built with **Next.js** and **TypeScript**.

The frontend focuses on a clean UI, responsive design, real-time updates, and smooth user experience for browsing and booking events.

---

## 🚀 Tech Stack

- **Next.js (App Router)** – React framework
- **TypeScript** – Type safety
- **Tailwind CSS** – Utility-first styling
- **shadcn/ui** – Accessible UI components
- **Redux Toolkit** – Global state management
- **Zod** – Form validation
- **Socket.io Client** – Real-time communication
- **Axios** – API requests
- **date-fns** – Date & time formatting

---

## ✨ Key Features

- Browse and search events
- Category-based event discovery
- Real-time ticket availability
- Secure Google OAuth login
- Smooth ticket booking flow
- Live notifications and updates
- Responsive design (mobile & desktop)
- User profile and ticket history

## 🧑‍💻 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/PraveenBaghelMaurya/EventLite-NextJs-Ticket-booking-platform.git
cd EventLite-NextJs-Ticket-booking-platform/client
```

### 2️⃣ Install Dependencies
```bash
npm install
```

### 3️⃣ Set Up Environment Variables
```bash
NEXT_PUBLIC_API_URL=http://localhost:8080
```

### 4️⃣ Run the Development Server
```
npm run dev
```
